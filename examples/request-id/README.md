# Helidon Request ID Example

---

This example shows how to inject `OciRequestId` directly into a REST endpoint method parameter.

## Build

From `examples/request-id`:

```shell
mvn package
```

## Run

From `examples/request-id`:

```shell
java -jar ./target/helidon-oci-examples-request-id.jar
```

Then call the endpoint:

```shell
curl -i http://localhost:8080/request-id
```

The response body includes the injected request ID and its segments, and the response also carries the
`opc-request-id` header generated by the request-id webserver feature.

## Test

From the repository root:

```shell
mvn -pl examples/request-id -am test
```
