# Getting Started With Helidon OCI 

You will need maven and Java 25 to use Helidon OCI.

To get started, see the instructions in the [Helidon OCI Reference Service](https://devops.oci.oraclecorp.com/devops-coderepository/namespaces/axuxirvibvvo/projects/HLDN/repositories/oci-helidon-reference-service/) repository.
