# Workflow

---

## Overview

This module provides generated configuration and service registry bindings for OCI Workflow-as-a-Service
(WFaaS) integration in a Helidon application.

For more details, please check [Workflow](../docs/workflow.md) under
[Helidon-OCI Native Services Integration Guide](../docs/README.md).

For a runnable sample application and HTTP-focused tests, see
[examples/workflow](../examples/workflow/README.md).
