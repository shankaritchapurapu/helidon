# Secret Service integration

---

## Overview

The Secret Service V2 (SSv2) project provides the following modules:
* `config-source` - SSv2 secrets retrieval over Helidon Config
* `tls-manager` - server and client mTls rotation

Runnable sample code is available in [examples/secret-service](../examples/secret-service/README.md).

For more details, please check [Secret Service V2](../docs/services/secret-service.md) under [Helidon-OCI Native Services Integration Guide](../docs/README.md).
