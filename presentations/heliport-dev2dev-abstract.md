# Heliport Dev2Dev Presentation Abstract

## Proposed Title

Heliport: Migrating Dropwizard 3 OCI Services to Helidon and Talon with Codex

## Invitation Abstract

You are invited to the Helidon Dev2Dev, an internal, bi-weekly meetup to discuss and demonstrate features of Helidon, Oracle's Java microservices framework. These meetups will look at the development of microservices using Helidon, Java and related technologies such as AI, OCI and Oracle Databases. We look forward to hosting you!

:reminder-5875: Heliport is a Codex skill designed to simplify the migration of Dropwizard-based OCI services to Helidon. This session introduces the tool, explains how it fits into the modernization journey, and walks through its guided migration workflow. We will explore how Heliport analyzes an existing application, automates common migration tasks, identifies areas that require developer attention, and generates reports to track progress and guide the remaining work. Whether you're planning a migration or already modernizing a service, this session will help you understand how Heliport can reduce effort, improve consistency, and accelerate the adoption of Helidon across OCI services.
